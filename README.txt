HOW TO PREVIEW
--------------
Double-click index.html to preview in your browser; click "Explore Publications" to open the second page.
For best results, you may use VS Code Live Server extension.

HOW TO PUBLISH
--------------
1. Create a PUBLIC GitHub repository, e.g., mywebsite.
2. Upload these five files to the ROOT of the repository (not inside a second folder).
3. In Settings > Pages: Deploy from a branch > main > /(root) > Save.
4. Wait for the GitHub Pages URL, then test index.html and publications.html on phone.

IMPORTANT: REVIEW BEFORE PUBLISHING
-----------------------------------
- "PhD in Mathematics" is correctly identified as IN PROGRESS. Update this only after formal award.
- Papers and DOI links were cross-checked against published journal records; review your official CV for completeness.
- The listed contact email is the work email from the earlier website. Replace with your preferred public contact address if needed.
- Service descriptions are offered areas, not promises of completed project outcomes.
- Experience descriptions are conservative, avoiding previously unverified numerical claims.
- This website is inspired by a general academic/professional site structure and is not a copy of its design or content.
- Google Fonts is used; typography falls back to system fonts when offline.
